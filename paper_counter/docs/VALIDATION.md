# 本轮清理的验证边界

本轮目标是只保留 regions、tracks，减少重复文件和一次性实验脚本，不重新调整两套算法的阈值和计数策略。

清理前已经将源码、配置、测试、说明和标注压缩备份到项目旁的 `paper_counter_cleanup_backups/`。
重复源码和旧打包产物也移到该备份目录；散落项目根目录的检测结果迁入
`output/historical_root_results/`，原始数据和 `output/` 中的历史检测结果没有删除。

## 清理前已有的问题

以下问题是在清理前的独立源码快照上确认的，不通过删除测试或修改算法来掩盖：

- `region_postvalidation.py` 存在残留语法错误，按原样保留；当前可选后处理加载时会进入既有回退逻辑。
- `test_paper_geometry.py::test_guarded_center_is_sampled_once_with_exact_affine_mapping` 失败：
  当前自适应区域选择后的图像与测试要求的直接仿射逐像素结果不一致。
- `test_region_counter.py::test_api_compact_and_full_boxes_use_explicit_coordinates` 失败：
  测试假设固定中心裁剪，而当前代码会自适应选择横向位置。

基准快照的保留算法相关测试为385通过、2失败。独立 narrow 与废弃条纹实验测试不在该基准内。
清理后已移除4项仅测试已删除 legacy 补峰函数的测试，其他 tracks/regions 测试继续保留。

## 核对内容

- 算法配置仅接受 tracks、regions，旧算法名明确报错。
- 从 narrow 文件迁出的裁剪、方向对齐工具与清理前保存的像素数组和仿射矩阵完全一致。
- 保留测试与基准失败列表对照，检查是否新增失败。
- 两张真实图片分别运行 regions、tracks，对比清理前后的计数、框坐标与实测轨迹点。
- 统一批处理验证两种输出，记录重叠问题但不修改原始检测结果。
- 打包时包含两套算法所需模块，排除历史输出、旧源码副本和退役算法。

## 最终结果

清理后共392项测试：390通过、2失败，失败项与清理前完全相同，没有新增失败。
两张真实图片分别运行两套算法，共4组输出的计数、框坐标和实测轨迹与清理前逐项一致。
迁出的几何工具通过数组及仿射矩阵相等检查；独立安装发行包后，两种算法预设和空图检测均通过。
`run_sample.ps1` 通过 PowerShell 语法解析。

具体结果见 `output/cleanup_validation/REPORT.md` 和 `SUMMARY.json`。

## regions 深度优化复跑（2026-10-19）

本轮对 regions 增加了原始局部对比候选、阶段数量账本、光学周期与物理纸厚分离、
保守的物理后验证，并取消固定分数最终删除。测试集与新测试共89张全部成功导出。
67张有确定真值，其中49张计数正确、18张有误差；上一版同一批次为31张正确、36张有误差。
所有89张均完成后验证，固定分数过滤删除数为0。结果和逐图阶段数据见
`output/batch_regions_revision_20261019_112609/`。

当前全量测试为399通过、2失败；两项失败仍是清理前已有的仿射逐像素比较和固定中心裁剪坐标假设，
没有新增失败。

## regions 边缘恢复复跑（2026-10-20）

针对新测试首框落在背景、以及部分测试图首尾纸张被保守前景掩膜漏掉的问题，增加了受限的边缘恢复：
只有原生条带有足够证据、候选位于最外侧、当前总数只少一到两张且候选框不与现有框重叠时才恢复。
它不会填补内部周期缺口，也不会因为一个固定厚度阈值直接生成框。

测试集与新测试共89张全部成功导出；73张有确定真值，其中61张正确、12张有误差。
新测试1.bmp至6.bmp分别得到44、56、56、56、56、56张，全部与更新后的真值一致。
按用户要求暂不把灰色淋膜纸和长条淋膜纸作为本轮重点；剔除这两类后剩余5张有误差。
完整结果见 `output/batch_regions_edgefix_recovery_20261019/`，误差明细见其中的
`误差报告.md` 和 `计数对照.csv`。
